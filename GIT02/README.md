sustavu Merlin kao i popratne vježbe. Preporuka je da prvo ponovite taj dio, jer smo sve u vezi rada s GitHubom prošli

![wrkflow](https://img.shields.io/badge/solutions-workflow-yellow?style=for-the-badge)

Vaš tijek rada (eng. workflow) treba slijediti sljedeći obrazac:

1. Prvi commit treba napraviti čim ste izradili nezavisnu logičnu cjelinu koju možete testirati
    * Vodite računa da se u imenovanju klasa, sučelja i metoda vodite logičkim asocijativnim načinom
    * Svako rješenje treba imati minimalno jedan paket naziva oblika `com.imeprezime.zadatak_n` gdje vaše ime i prezime
      pišete spojeno s malim slovima i bez hrvatskih dijakritičkih znakova, a `n` predstavlja oznaku broja zadatka (
      repozitorij) &rarr; po potrebi možete kreirati i više paketa, ali paket s **main** dijelom programa treba biti
      navedenog oblika
2. Svaki sljedeći commit je vaš izbor prema općim načelima koja smo nekoliko puta navodili na vježbama
2. Predzadnji commit je radna verzija rješenja
3. Zadnji commit je finalna verzija rješenja &Rarr; ona koju vi smatrate finalnom verzijom

![important](https://img.shields.io/badge/important-IMPORTANT-red?style=for-the-badge&logo=ASKfm)
